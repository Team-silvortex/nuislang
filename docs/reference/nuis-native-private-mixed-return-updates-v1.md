## One Outward Ancestor

A terminal selection may write its already authorized exact owned unsealed bool
ancestor and one exact owned unsealed bool child. The child must already be
defined in the same private prefix and absent from the entering scope.
Read-only classification requires exactly those two eligible actual source
write names, with a shared 64-source-statement counter and eight-selection depth
bound. A private proof token grants no additional outward result or definition.

Original source statements reuse the existing single-target staging proof, one
statement at a time. Ancestor-before-child and child-before-ancestor orders both
preserve current source versions, checks, short-circuit effects and seals.
Single-target prefix selections retain their existing routes. Nested terminal
mixed selections may recurse, but only the actual current ancestor is exported.
Skipped ancestor writes retain its actual incoming value, not the child's result.

The root still requires actual ancestor source write evidence. Fresh names,
other entering bindings, constants and extra eligible child targets cannot
manufacture authority. A prefix mixed selection with an observed child
continuation is rejected: a terminal one-result join cannot silently discard
the child version needed by later source work. That is the next separate proof.

## Original Work And Limits

There is no invented transport source work. Capture discovery distinguishes old
reads from definite replacement versions and delegated permission from actual
definitions. Private children, seals and unused locals stay inside their scope.
Failure remains atomic before helper or generated-name installation.

The whole tree shares 64 nodes, 256 expressions, 32 logical edges, eight selection
levels, below-32 expression depth and 31 captures plus a gate. Each arm retains
at most 16 prefix statements plus one terminal statement. The read-only classifier
does not consume or enlarge the original execution budget.

Six NIR units cover both orders/polarities, nested terminal selections,
single-target prefixes, old-read/replacement/conditional captures, seals, unused
work, and exact nine nodes / 18 expressions / three logical edges accounting.
One-less rejection and adjacent prefix 16/17, nodes 64/65, edges 32/33, depth 8/9,
discovery 64/65 and capture 31/32 boundaries remain independently checked.
Negative and mutated-NIR cases cover no-write roots, extra entering/child targets,
sealed/nonbool/borrowed/optional/generic writes, hidden logical work, print,
return, loop, prefix child continuations and late sibling leaks.

## Remaining Boundary

Mixed ancestor/private-child prefix selections with observed child continuations
need explicit source-version transport without widening arbitrary incoming or
multi-target outward write authority. Root no-write candidates, hidden ordinary
leaves, mixed/partial exits, loops, resources and generalized effects remain
separate.
The later [flat mixed-continuation proof](nuis-native-private-flat-mixed-continuations-v1.md)
records the first bounded prefix extension. The 631-test receipt above is
historical, not fresh acceptance for that extension.
This scalar-host proof does not establish new GPU/Linux/Windows
execution, measured speedups, authentication, formal memory safety or completed
self-hosting. Full workspace and strict Clippy acceptance remain separate.
