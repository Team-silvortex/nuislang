# Native Private Float Pair Continuations V1

Status: worktree follow-up after Git baseline `304c49cd` (`beta-0.16.4`).
This extends the [i64-pair proof](nuis-native-private-i64-pair-continuations-v1.md)
with exact bool/f32 and bool/f64 private continuation values. The source result
remains one bool; this is not a public tuple, new ABI or arbitrary multi-write
permission.

## Exact Typed Carrier

The shared owned carrier has private fields `owner: bool` and `child: f32`
or `child: f64`. It reuses NIR structs, YIR owned aggregate returns and existing
backend scalar-layout admission. Both projections read the same selected result.
There is no numeric packing, narrowing, pointer encoding, replay or new aggregate
heap allocation in the admitted native session slice.

The bool/bool and bool/i32 scalar codecs remain unchanged; exact bool/i64 now
uses the same kind-directed owned installer. Inactive helpers return only exact
typed literal zeros: bool false and the child's positive-zero scalar literal.
Private names and layouts are installed only after candidate proof succeeds.
Source type names and actual temporary suffix collisions remain reserved.

Whole-original-forest preflight, lexical isolation, constant seals and source
budgets are unchanged: 64 nodes, 256 expressions, 32 logical edges, eight
selection levels, 16 statements per arm/continuation, 31 captures plus a gate.
The classifier requires actual writes to the existing bool owner and exactly
one defined, unsealed prefix-private child absent from entering scope.
Incoming or third writes, resources, modifiers, generic/optional types, hidden
logical leaves and partial exits remain excluded. Numeric writes require the
classified Child token, not a fabricated bool Target.

Twelve NIR units cover both widths, write orders/polarities, terminal/nested/
sequential joins, retention, guards, full fields, name/module atomicity, source
authority and lexical/capture boundaries. The exact six-node/twelve-expression/
zero-logical-edge case passes; one less node or expression rejects.
2/5/9 selections install 4/10/18 helpers and 2/5/9 private layouts without
remaining-tail clones.

## Floating Expression Consistency

The frontend already lowered IEEE scalar comparisons, but NIR inference omitted
floating equality/order results. It now recognizes all six comparison operators
as bool for compatible exact owned scalar operands, including nested boolean
comparisons and inferred local bindings. Two regression units reject cross-width
operands, resources and ref/optional/generic modifiers.

The shared control-value proof admits these exact comparisons. The effectful
expression proof also admits the exact pack/unpack nodes generated by source
floating negation, with existing expression-depth/work accounting.
Sign changes use the existing bit-preserving source negation contract rather
than subtraction from floating zero. Floating division/remainder admission
and resource/effect authority are not widened.

## Native Bit Evidence

The [Nuis source fixture](../../tools/nuisc/tests/native_application_bridge/return_float_pair_mixed_logical_effectful_scalar_selections.ns)
uses a thirteen-field state, a private floating child, nested/sequential joins,
retained arms, current reads, checked unused work and one bool exit.
The same fixture is compiled independently as f32 and f64.

Two native raw-word tests use twelve seeds at each width and four flag
combinations, in ordinary and reversed YIR inventory order: 576 lifecycle
transitions across four real host executables. Inputs include positive/negative
zero, signed subnormals, finite values, positive/negative infinity, quiet NaNs
with payloads and negative signaling NaNs.

The probe observes the actual carried argument inside the compiled
`after_work` source callee using a LLVM bitcast. It replaces no computation,
join, helper result or source return. An independent IEEE comparison/sign-bit
oracle checks the full output words, carried child words, bool results, source
print order, callback status, state sentinels and zero aggregate allocation/drop
counters. Event and close consume the actual preceding callback state.
Two negative probe units reject replacing exact word codecs with numeric casts.

Two artifact units cover both widths, exact state/private owned layouts, leading
guards, at least nine checked functions, at least sixteen guarded calls,
local transitive Effect paths, print-policy authority and source-free verification.
Removing required Effect edges or print grants remains a rejection.

## CLI Evidence

Two CLI workflows compile both widths with four exactly representable decimal
seeds and four flag combinations. Fresh builds, cache hits and three source-free
restorations define 480 lifecycle transitions. All nine selected helper sites at
each width are tested for traps before later work, caller continuation or state
publication. Inactive proof denominators are zero.

The decimal CLI parser is not evidence of NaN payload preservation; that belongs
to the separate raw-word probe above. Source, manifest and project cache are
deleted before restoration. Packaging policy and executable bytes stay identical.
