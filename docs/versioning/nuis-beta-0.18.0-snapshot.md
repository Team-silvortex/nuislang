## Separate Routes And Remaining Gates

The embedded-YIR image/window application, bounded native CPU callbacks and
private Nsld Mach-O/ELF images remain different execution routes. Acceptance in
one route does not certify the others or a self-contained heterogeneous engine.

General resource/I/O/async capture, changing backedges, wide private captures,
provider retirement, broader GPU/Linux/PE parity and complete native application
packaging retain their own gates. Stable ABI and global memory-safety claims
require evidence beyond these scoped CPU witnesses.

Five bounded self-hosting preparation gates are closed, but actual compiler
ownership transfer and candidate native-object emission are separate. Follow
[self-hosting readiness](../reference/nuis-self-hosting-readiness.md); the
approximate stage2-equivalent target remains `gamma-0.5.*` through `gamma-0.10.*`,
not a release deadline.
